🚀 Guía de Publicación en Tiendas

Instrucciones técnicas y metadatos para compilar y subir Sudoku Arena a Google Play Store y Apple App Store.

📦 1. Estructura de Ficheros Preparada en el Proyecto

El proyecto en c:\laragon\www\sudoku-arena ya contiene todos los archivos y configuraciones necesarios:

  • manifest.json: Web App Manifest con orientación vertical, colores oscuros y metadatos PWA.
  • capacitor.config.json: Configuración del Bundle ID (com.sudokuarena.mobile), nombre oficial y Splash Screen nativo.
  • package.json: Dependencias de Capacitor oficiales listas para instalar.
  • icons/: Iconos vectoriales y rasterizados de alta resolución (192px y 512px).
  • privacidad.html: Política de privacidad obligatoria requerida por Google Play y Apple.

🛠️ 2. Pasos para Compilar en Android (Google Play)

Requisitos: Ordenador con Node.js y Android Studio instalado.
  1. Abrir la terminal en la carpeta del proyecto: 
    cd C:\laragon\www\sudoku-arena
  2. Instalar dependencias de Capacitor: 
    npm install
  3. Empaquetar y sincronizar con Android nativo: 
    npm run build
npx cap add android
npx cap sync
  4. Abrir el proyecto directamente en Android Studio: 
    npx cap open android
  5. En Android Studio:
    • Ir al menú: Build > Generate Signed Bundle / APK.
    • Elegir Android App Bundle (.aab) (el formato estándar de Google Play).
    • Seleccionar o generar la clave de firma digital (keystore).
    • Obtendrás el archivo .aab listo para subir a Google Play Console.

🍏 3. Pasos para Compilar en iOS (Apple App Store)

Requisitos: Un Mac con Xcode instalado y cuenta Apple Developer.
  1. En el Mac, abrir la terminal en la carpeta del proyecto: 
    npm install
npm run build
npx cap add ios
npx cap sync
  2. Abrir el proyecto nativo en Xcode: 
    npx cap open ios
  3. En Xcode:
    • En la pestaña Signing & Capabilities, seleccionar tu cuenta de desarrollador (*Team*).
    • Conectar un iPhone o usar el simulador de iOS para probarlo.
    • Para enviar a la tienda: Seleccionar dispositivo Any iOS Device (arm64) y pulsar Product > Archive.
    • Pulsar Distribute App para subir la compilación a App Store Connect / TestFlight.

Descripción Completa (Google Play y App Store)

¿Cansado de los sudokus que se resuelven adivinando? Bienvenido a Sudoku Arena.

Sudoku Arena es un juego de sudoku táctico diseñado para desafiar tu agilidad deductiva real sin tanteo a ciegas. Cada casilla tiene un valor en puntos según la técnica lógica humana necesaria para resolverla (candidatos únicos, números ocultos, pares y cadenas).

CARACTERÍSTICAS PRINCIPALES:
⚡ 4 Niveles de Dificultad Real: Fácil, Medio, Difícil y Endemoniado, con soluciones únicas garantizadas por algoritmo.
🎯 Motor de Puntuación Cognitiva: Cada acierto suma según su complejidad lógica.
🔍 Inspección Quirúrgica (Lupa): Consulta las posibilidades de una casilla activa con coste de oportunidad en tu techo de puntos.
⚡ Rayos X Globales: Escanea todos los candidatos del tablero con penalización matemática escalonada.
🧠 Índice de Autonomía Mental: Descubre tu rango real (Gran Maestro Puro, Lógico Quirúrgico, Resolutor Pragmático o Nivel Muy Bajo).
📋 Libro Mayor de Auditoría: Revisa la trazabilidad de cada acierto, fallo y deducción.
⚔️ Modo Duelo / Códigos Compartibles: Reta a tus amigos a resolver exactamente el mismo tablero con un código de partida único.

100% PRIVADO Y SIN PUBLICIDAD:
